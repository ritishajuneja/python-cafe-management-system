# Rishu's Bistro ☕

Rishu's Bistro is a beginner-friendly Python cafe management system that simulates a real café ordering and billing experience.

The project was initially built using basic Python concepts and later upgraded with loops, dynamic ordering, GST calculation, and receipt generation.

---

## Features

- Interactive cafe ordering system
- Dynamic multiple-item ordering using loops
- Cafe menu using Python dictionaries
- Automatic bill calculation
- GST/tax calculation
- Receipt generation
- Payment method selection
- Beginner-friendly console application

---

## Concepts Used

- Variables & Data Types
- User Input
- Conditional Statements
- Loops (`while` loop)
- Dictionaries
- Lists
- Basic Billing Logic

---

## Project Files

- `menu.py` → Initial version of the cafe system
- `updated_menu.py` → Improved version with loops, GST, and receipt generation
