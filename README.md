# Rishu's Bistro ☕

A beginner-level cafe management system built using Python.

This project simulates a simple cafe ordering system where users can:
- Select menu items
- Calculate total bill
- Choose payment method

## Concepts Used
- Dictionaries
- Conditional Statements
- User Input
- Variables
- Basic Billing Logic

## Features
- Cafe menu system
- Bill calculation
- Multiple item ordering
- Payment method input
